# 녹조 반응 실험실

녹조를 배양하고 활성탄, 참나무 낙엽 추출액, 볏짚 추출액, 수생식물(부레옥잠·개구리밥·검정말)로 정화했을 때의 반응을 시간별로 예측하고 공부하는 가상 실험 페이지입니다.

- 1시간 단위 계산: 밤낮의 pH·용존산소 변화, 날씨·바람·비·증발 반영
- 용기 용량과 비커별 투입량 저장, 녹조 양 조절, 최대 90일 관찰
- 7단계: 준비 → 배양 → 정화 처리 → 관찰·판정 → 재증식 확인 → 수생식물 비교 → 결과 정리
- 반응별 화학·생명과학 설명, 시간 흐름, 학생이 확인하는 방법, 근거 수준과 출처
- 정화 판정 기준(대조군 대비 감소, 호소 생활환경기준 클로로필 a, 유지 기간, 산소)
- 측정 분석(시간·대조군 대비·24시간·두 지표 관계·요약 통계), 실측값 입력, CSV

교육용 단순 모델이며 수치는 예측값입니다. 불확실한 값은 페이지에 '불확실·가정'으로 표시했습니다.
